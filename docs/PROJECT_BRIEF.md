# SHITPRINT — Project Brief

## Project Name

ShitPrint

## Project Type

Modern streetwear / graphic T-shirt e-commerce website.

## Purpose

Create a highly interactive, visually impressive clothing website for a college mini project.

The website should look like a real modern streetwear brand rather than a generic e-commerce template.

The website must be:

- Modern
- Trendy
- Bold
- Interactive
- Responsive
- Fast
- Visually polished
- Easy to navigate

## Core Pages

Create 3 main experiences:

1. Home
2. Shop
3. Product Details / Cart

The navigation should allow the user to move between all sections smoothly.

## Brand Personality

ShitPrint is a fictional streetwear brand focused on expressive, humorous and unconventional graphic T-shirts.

Brand personality:

- Bold
- Playful
- Youth-oriented
- Slightly rebellious
- Minimal but expressive
- Internet/streetwear culture inspired

Do NOT make the design childish.

It should look premium despite the humorous brand name.

## Target Audience

College students and young adults approximately 18–30.

## Main CTA

"SHOP THE DROP"

Secondary CTA:

"EXPLORE COLLECTION"

## Product Images

The user will provide actual T-shirt images.

Use those uploaded images as the actual product assets.

Do not replace them with generated placeholder images.

If multiple images are provided, inspect them and automatically create product entries for them.

## Important

This is a frontend mini project.

No real payment gateway is required.

No real authentication is required.

No real database is required.

The cart should work using frontend state/localStorage.

The checkout can be a simulated checkout experience.
