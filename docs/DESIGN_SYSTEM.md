# SHITPRINT — Design System

## Overall Visual Direction

Create a premium contemporary streetwear website.

Visual inspiration:

- Modern streetwear brands
- Editorial fashion websites
- Minimal e-commerce
- Contemporary typography
- Gen-Z fashion interfaces

Do not copy any existing brand.

## Color Palette

Primary background:

#F5F3EE

Secondary background:

#111111

Primary text:

#111111

Secondary text:

#6B6B6B

Accent:

#DFFF00

Use the neon accent sparingly.

The website should primarily feel monochrome with occasional high-energy accent elements.

## Typography

Use a bold modern sans-serif font.

Suggested:

- Inter
- Space Grotesk
- Satoshi
- Geist

Use:

- Very large typography for hero headings
- Medium/bold typography for product names
- Small uppercase labels for categories

Example hero:

"WEAR YOUR
BAD DECISIONS."

or

"PRINTS WITH
ATTITUDE."

## Layout

Use generous whitespace.

Use large product imagery.

Use asymmetric editorial layouts where appropriate.

Avoid excessive rounded cards.

Avoid generic SaaS-style UI.

Avoid excessive gradients.

Avoid excessive shadows.

## Buttons

Primary button:

Black background
White text
Sharp or slightly rounded corners

Hover:

Accent background
Black text

Buttons should have subtle animations.

## Product Cards

Product cards should contain:

- Large product image
- Product name
- Price
- Category
- Optional badge

Hover behavior:

- Image slightly zooms
- Secondary image can appear if available
- Quick Add button appears
- Product information shifts subtly
- Smooth transition

## Navigation

Desktop:

SHITPRINT logo on left.

Navigation:

HOME
SHOP
ABOUT

Right side:

SEARCH
CART

Mobile:

Logo
Menu
Cart

Navigation should remain sticky.

## Animations

Use Framer Motion.

Animations should be smooth and intentional.

Use:

- Page entrance animations
- Fade-up animations
- Image hover zoom
- Button hover animations
- Cart drawer animation
- Product modal animation
- Smooth scrolling
- Micro-interactions

Do not over-animate everything.

## Cursor / Interaction

If practical, add subtle hover states.

Do not create distracting custom cursor effects unless they genuinely improve the design.

## Responsive Design

Desktop:

1440px+

Tablet:

768px–1439px

Mobile:

Below 768px

The website must look polished at all sizes.
